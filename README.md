# 🌐 NetCraft - Navigateur Web pour ComputerCraft

**NetCraft** est un navigateur web complet et un serveur HTTP conçu pour **CC:Tweaked** (ComputerCraft Tweaked) sur Minecraft. Il introduit le protocole `net://`, supporte le rendu HTML, l'exécution sécurisée de scripts Lua côté client, un système de DNS basé sur Rednet, et une architecture client/serveur robuste.

## 🎯 Fonctionnalités Principales

- 🌍 **Navigation Web** : Surfez sur le web avec le protocole `net://`
- 🖥️ **Rendu HTML** : Moteur de rendu supportant `<h1>`, `<h2>`, `<p>`, `<a>`, `<img>`, `<form>`, et plus
- 🔐 **Scripts Lua Sécurisés** : Exécution sandboxée de scripts Lua côté client
- 📡 **DNS via Rednet** : Résolution de noms de domaine sans configuration manuelle
- 💾 **Système de Cache** : Cache intelligent avec expiration automatique
- 📚 **Historique & Signets** : Navigation avec historique complet et gestion des favoris
- 🛠️ **API Développeur** : API publique pour créer vos propres applications web
- 📝 **Formulaire POST** : Support complet des formulaires HTML avec parsing automatique
- 🎨 **Rendu NFP** : Support des images NFP (format ComputerCraft)
